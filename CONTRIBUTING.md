# Contributing Guidelines

Thank you for your interest in contributing to **Broke But Functional**!

## Development Setup

1. Fork & clone the repository:
   ```bash
   git clone https://github.com/gopinathscse2024/broke-but-functional.git
   cd broke-but-functional
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
4. Verify production build:
   ```bash
   npm run build
   ```

## Code Quality Standards

- Maintain strict TypeScript typing without `any`.
- Keep components modular and single-responsibility.
- Ensure all new features retain WCAG AA contrast standards and keyboard navigability.
